# The objectivity audit — borrowed scoreboard, no score

The thesis's measurable spine (mirrors Menlo's `impact_audit.md`). The sports/performance
metaphor _sounds_ objective ("high performers," "judged by outcomes," "raise the bar").
Does anyone actually **define how performance is measured**? Scanned across all 11
companies' careers/culture mission_brand text (cohort + adopters).

|                                                                                                                        | chunks         | share  |
| ---------------------------------------------------------------------------------------------------------------------- | -------------- | ------ |
| mission_brand chunks scanned                                                                                           | 1103           | —      |
| **Claim** objective performance / merit (high performer, the bar, judged by, results-driven, star performer, A-player) | **78**         | **7%** |
| **Define** an actual performance metric (measured by X, KPI, scorecard, quota, percentile, ranking)                    | **0 credible** | **0%** |

The 10 regex "metric" hits are all false positives on inspection:

- **Netflix (2017–2022) — the smoking gun:** the only "ranking/quota" language is a
  _negation_ — _"We have no bell curves or rankings or quotas such as 'cut the bottom 10%
  every year.'"_ Netflix demands you be a "high performer" judged by the **keeper test**
  (a manager's gut answer to "would I fight to keep them?") while **explicitly refusing
  any defined measure.** The model that most loudly invokes the professional-sports-team
  scoreboard is the one that most explicitly declines to keep score.
- Google "ranking" → about _revenue_; Amazon "metric" → "audit frequently" (generic);
  Amazon "ranking" → a third-party employer award; Airbnb → _"success is measured by
  pride"_ (explicitly subjective).

## Finding

Pervasive objectivity rhetoric, **no defined metric anywhere.** The language borrows
sports' objectivity (the regulation hoop, the scoreboard, the box score) without its
measurability. Performance in this copy is asserted as objective and judged by
discretion — which is precisely the gap the thesis names: _the sports metaphor launders
subjective judgment into false objectivity, and into that gap bias enters._ Netflix's own
deck even concedes the analogy is "Good, but Imperfect."

## Per-concept matrix

Same gap, concept by concept — every claim, no metric, the cut made by discretion. The
third column is interpretation (the judgment the missing metric leaves behind).

| Concept | Claims objectivity? | Defines a metric? | How the cut is actually made |
|---|---|---|---|
| Keeper test | Yes | No | Manager's gut — "would I fight to keep you?" (power decision) |
| Adequate → severance | Yes | No | Subjective label of who is "adequate" / "unremarkable" |
| High performer ≫ average | Yes | No | Undefined comparison to an undefined "average" |
| Raise the bar | Yes | No | Hiring-manager discretion about "above the bar" |
| Judged by outcomes | Yes | No | Unspecified "outcomes" / "impact" |
| Talent density | Yes | No | Concentration of an undefined "high performer" |
| Only the best / A-players | Yes | No | Undefined "best" / "top talent" |

## Soft ⇄ hard mapping (interpretation)

Companies that never printed "keeper test" still make the same cut with vaguer words:
"keeper test" ⇄ "we hire only the best"; "adequate → severance" ⇄ "we raise the bar";
"a team, not a family" ⇄ "a high-performance, results-driven team". Each pair is a
subjective filter dressed as objective merit.

## Guardrail

This measures the **absence of stated metrics in self-presentation**, not the presence of
bias. The claim stays narrow: the objectivity is rhetorical, not defined. Whether the
resulting discretion produces biased outcomes is the interpretive thesis (Phase 4),
grounded in external performance-review-bias literature — not a measured output here.
